# 検索クエリー一覧

## 検証(1)：表記揺れ

| 分類 | 検索クエリー | ヒットさせたい表記 |
| --- | --- | --- |
| 文字種の違い | さーばー | サーバー |
| 異体字・旧字体 | 齋藤 | 斎藤 |
| 同義語・略称 | スマホ | スマートフォン |
| 数字・単位の表記 | 1000円 | 1,000円 |
| 入力ミス・誤記 | データベス | データベース |
| カタカナ・英字の表記揺れ | postgresql | PostgreSQL |

### 確認事項

- 目的の表記を含むチケットがヒットするか
- 検索順位
- ノイズの多さ

## 検証(2)：従来の検索では対応しにくい検索

症状から原因を検索するケース。

| 検索クエリー | 確認したいこと |
| --- | --- |
| 接続できない | コネクションプールの枯渇を検索できるか |
| データベースに接続できない | 対象を明確にすると検索結果が改善するか |
| 業務システムを使おうとしても入口で拒まれる | 大きく異なる表現でも関連するチケットを検索できるか |

## 検証(3)：文脈を踏まえた検索

新人の鈴木さんと鈴木部長を区別できるかを検証する。

| 検索クエリー | 確認したいこと |
| --- | --- |
| 鈴木 | 両者が検索結果に含まれるか |
| 新人の鈴木さん | 新人の鈴木さんを優先できるか |
| 鈴木部長 | 鈴木部長を優先できるか |
| 鈴木　承認済みチケット | 役職を明示せずに承認者を区別できるか |
| 鈴木さんが承認したチケット | 承認する側の人物を区別できるか |
